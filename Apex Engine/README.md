# Apex Engine

A Roblox UI library designed and developed by Barlas.

## Usage

```lua
local ApexEngine = loadstring(game:HttpGet("https://raw.githubusercontent.com/B5RLAS/ApexEngine/main/ApexEngine.lua"))()

local Window = ApexEngine:CreateWindow({
    Title = "APEX ENGINE",
    User  = "YourName",
    Till  = "Lifetime",
})
```

## Features

- Tabs & Subtabs
- Checkboxes, Sliders, Dropdowns
- Color Pickers, Keybinds, Textboxes
- Buttons, Labels, Separators
- Draggable window, blur effect, page animations
- Config/flag system

## Toggle

Press `Insert` to show/hide the menu.
